Daily Automation
One exact time per vendor

When a daily schedule is enabled, the background worker will queue that vendor once per day at the configured local server time. If the app was down at that moment, it will catch up after startup once the scheduled time has already passed.

Behavior
How the scheduler decides
Daily schedules take priority over the old interval-based scheduler for that vendor.
Local server time Times on this page follow the timezone of the machine running the app.
One run per day The scheduler will not queue the same vendor again once a scan job already exists after that day’s scheduled time.
Readiness still applies Targets, credentials, and queue state must still allow a scan before a scheduled run can start.
